# Provenance and publication transformations

`SOURCE_COPY_RECORD.json` maps each selected source using an archive-neutral R1/R2/R3/P identifier, its original SHA256, the public SHA256, and whether bytes are identical. Any absolute local path string in a public JSON copy is replaced by an `archive://basename` reference. Numerical values, labels, seed/fold/log/sample IDs and scientific outputs are not changed. Such a transformed JSON file has a new hash and is not claimed byte-identical. Public copies are never written back into the original archive.

The R1 public scoring wrapper removes only an optional refit interface/branch and updates its docstring/import; its default saved-model scoring arithmetic is unchanged. R2 and R3 compact verifiers are otherwise retained as documented. Version 1.0.1 adds the author, affiliation, email and research-advisor metadata to the manuscript; this changes the PDF and LaTeX main bytes. The scientific text, bibliography, numerical results, tables and vector figures are unchanged. The source-copy record identifies the actual manuscript source and public copies for this revision; no byte identity with the earlier anonymous manuscript is implied.

`PUBLIC_RELEASE_MANIFEST.json` binds the current public source scope, excluding itself and the standard SHA256 list to avoid circular hashes. `PORTABILITY_CHECKS.json` preserves the initial v1.0.0 new-repository smoke checks; those historical numerical checks do not represent a new v1.0.1 experiment or a rerun of the scientific pipeline. `academic-writing-toolkit/` preserves the initial release's offline text/BibTeX checks, with their exact historical scope. The v1.0.0 tag and release retain the earlier public files. The complete local historical archive, all original failures and Windows native proof are preserved locally; the public companion deliberately omits machine/process/session controls and original raw data.
