# Academic Writing Toolkit scope

For the initial v1.0.0 public release, the root English README was submitted to `review_paragraph_logic`; the tool returned zero issues. The existing ten-entry bibliography was submitted to `verify_bibtex_references`; it returned zero issues, with no online sources or metadata lookups. The recorded outputs are historical offline document-assistance checks, not external peer review, authentication of every citation, or validation of scientific correctness.

The separate same-workflow read-only v1.0.0 publication review checked English/Chinese READMEs, rights/data notes, the reproduction guide, CFF metadata and the public R1 wrapper. It found no publication-blocking conclusion or accidental-refit issue. The public R1 helper's optional refit flag/branch is removed; documented R2 SQLite usage retains `--read-only`. No scientific candidate was added or selected through these checks.

The current README and bibliography byte hashes are bound by the public release manifest. Version 1.0.1 adds author and research-advisor metadata and therefore changes manuscript/PDF and README bytes; the accepted scientific content and values are unchanged. The earlier tool receipts are not represented as a fresh review of the revised README. Authorship and research-advisor attribution were supplied by the author, not inferred from toolkit output. No toolkit output supplies a DOI, venue acceptance, safety certification or external independent replication.
