# Matched Conditioning in Layer-Gate BEV

This is the complete English LaTeX source for the bounded 2026-10-28 follow-up. The canonical compiled paper in the public repository is `paper/matched-conditioning-study.pdf`.

Compile `main.tex` with an ordinary IEEEtran installation, BibTeX, and PDF LaTeX, or with Tectonic. The source uses IEEEtran, standard LaTeX mathematics, Booktabs, Graphicx, Hyperref and the IEEEtran bibliography style. Obtain IEEEtran through its upstream distribution; its class and bibliography style are not vendored here. All authored sections, bibliography records, generated tables and figures are included.

```text
latexmk -pdf main.tex
```

The paper reports all three original seeds and fixed secondary conditions. It does not establish stable efficacy, external validation, a causal path contribution or calibrated safety. The public compact companion reproduces saved critical matching-status/count arithmetic. It does not rerun detector training, box matching or SDK metrics.
